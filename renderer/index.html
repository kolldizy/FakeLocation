Setup checklist

ON THE IPHONE
1
Install Apple's USB driver
Install “Apple Devices” from the Microsoft Store (or iTunes). This provides the Apple Mobile Device Service that exposes the iPhone through usbmuxd.
2
Connect with a data cable
Charge-only cables expose the device to Windows power but not as a USB device.
3
Tap Trust
Unlock the iPhone and accept the “Trust This Computer?” prompt, then enter the passcode.
4
Enable Developer Mode
Settings → Privacy & Security → Developer Mode → on. The iPhone restarts and asks for the passcode. Location Studio never changes this setting for you.
5
Keep the phone unlocked while simulating
Some developer services refuse to start on a locked device.

Limitations

READ THIS
⚠
The override is not universal

Apple's developer location channel changes the position reported to CoreLocation. Apps that use independent positioning — Find My device tracking, carrier or emergency services, some streaming and banking apps with their own integrity checks — may ignore it or show something different.

ⓘ
Stopping restores normal behaviour

Pressing Stop sends the clear command and closes the developer session. If the cable is unplugged, the iPhone returns to its real GPS automatically because the session ends with the connection.

ⓘ
Pause granularity

Pause stops further updates at the next update interval. The iPhone keeps reporting the last published coordinate until you resume or stop.
