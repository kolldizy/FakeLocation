Setup checklist

ON THE IPHONE
1
Install Apple's USB driver
Install “Apple Devices” from the Microsoft Store (or iTunes). This provides the Apple Mobile Device Service that exposes the iPhone through usbmuxd.
2
Connect with a data cable
Charge-only cables expose the device to Windows power but not as a USB device.
3
Tap Trust
Unlock the iPhone and accept the “Trust This Computer?” prompt, then enter the passcode.
4
Enable Developer Mode
Settings → Privacy & Security → Developer Mode → on. The iPhone restarts and asks for the passcode. Location Studio never changes this setting for you.
5
Keep the phone unlocked while simulating
Some developer services refuse to start on a locked device.
ⓘ
A wireless link is unplugged on purpose

While the cable is attached, usbmuxd prefers it, so a “successful” tunnel would prove nothing about Wi-Fi. Connect the wireless link with the cable out; this app says so instead of quietly falling back.

Verify on the device

Open Maps or Find My on the iPhone, then capture its screen. This is the only independent check that the simulated position reached the phone — the bridge never claims success on its own.

Limitations

⚠
The override is not universal

Apple's developer location channel changes the position reported to CoreLocation. Apps that use independent positioning — Find My device tracking, carrier or emergency services, some streaming and banking apps with their own integrity checks — may ignore it or show something different.

ⓘ
Stopping restores normal behaviour

Pressing Stop sends the clear command and closes the developer session. If the cable is unplugged, the iPhone returns to its real GPS automatically because the session ends with the connection.

ⓘ
Pause granularity

Pause stops further updates at the next update interval. The iPhone keeps reporting the last published coordinate until you resume or stop.

First-time wireless setup

ONE TIME PER DEVICE
1
Pair over USB once
Unlock the iPhone, connect a data cable and tap Trust. This creates the pairing record the Wi-Fi path authenticates against — but it does not turn Wi-Fi on by itself.
2
Enable syncing over Wi-Fi
With the cable still attached: in Apple Devices (or iTunes) open the device options and turn on “Sync with this iPhone over Wi-Fi”. On newer iOS the same option lives in Settings → General → iPhone Transfer.
3
Same network, no client isolation
The iPhone and this PC must sit on the same subnet, and the access point must forward multicast DNS. Guest and VPN-isolated networks block the discovery that the wireless path depends on.
4
Keep the Apple Mobile Device Service running
Windows reaches a network iPhone through the same usbmuxd pipe that serves the cable, so “Apple Mobile Device Service” must be started.
5
Developer Mode stays a manual step
Settings → Privacy & Security → Developer Mode → on, then restart the iPhone. Location Studio never changes this setting for you.
6
iOS 17.0–17.3 needs one more thing
Those versions can only open the developer tunnel from a RemotePairing record, which must be created once while the phone is on the cable. iOS 17.4 and newer reach it through the CoreDevice proxy without that bootstrap.

Privacy

WHAT THIS APP READS
Location Studio talks to the local Apple Mobile Device Service and to pymobiledevice3 in a child Python process. It reads device identity, pairing state and Developer Mode state to decide what it can honestly do, counts pairing record files without reading them, and writes no telemetry anywhere.
